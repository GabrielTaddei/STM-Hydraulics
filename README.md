# STM Hydraulic Services

Site estático pronto para publicação no GitHub Pages.

## Publicar

1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (o `index.html` deve ficar na raiz).
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)`.

Os links e arquivos usam caminhos relativos, então o site funciona tanto em `usuario.github.io` quanto em `usuario.github.io/nome-do-repositorio/`.

O formulário da página de contato abre o aplicativo de e-mail do visitante. Os botões de WhatsApp abrem o número da STM. Não há servidor ou banco de dados.
